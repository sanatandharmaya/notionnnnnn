# Review reports

This directory currently contains the access checkpoint for the source review:

- [Source inventory](source-inventory.md) identifies the three unique supplied roots.
- [Reading coverage](reading-coverage.md) records what has and has not been read.
- [Progress](progress.md) records the blocker and next action.

Category, duplicate, conflict, and traceability reports will be created after the relevant sources can be read. Creating empty category reports now would imply an unsupported taxonomy.
